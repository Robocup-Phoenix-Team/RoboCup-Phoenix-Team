Notre équipe

Nous sommes une équipe du collège Notre Dame des Oiseaux, passionnée par la robotique, la programmation et les défis technologiques.

Objectif:

Notre objectif est de concevoir, programmer et améliorer un robot capable de participer aux épreuves de la RoboCup Junior soccer balle passive.

Nous travaillons sur :

🤖 la conception du robot
💻 la programmation
🔧 l’optimisation
🧠 la stratégie employée pour gagner

Technologies utilisées

Programmation : editeur visuel de python
Électronique : pixy cam, moteurs encodeurs capteur quadrgb, ESP32, roues omnidirectionnelles
Modélisation 3D : logiciel de CAO en ligne onshape
Impression 3D
